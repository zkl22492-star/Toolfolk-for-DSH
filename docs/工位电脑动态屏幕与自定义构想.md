# 工位电脑动态屏幕与自定义构想

记录日期：2026-09-13。状态：已保存的产品构想，尚未实现。

## 目标

让六台工位电脑成为具有岗位特色的小状态屏：空闲时提供有趣、安静的装饰画面，工作时反映真实任务进展，并允许用户分别设置各台电脑。

## 三种屏幕状态

| 状态 | 内容 |
| --- | --- |
| 空闲 | 用户壁纸、像素水族箱、小鲸鱼游动、时钟、缓慢变化的天气插画 |
| 工作 | 对应岗位的操作摘要与轻量动画 |
| 需要关注 | 等待确认、失败、完成提示，点击查看详情 |

任务画面由真实事件驱动；装饰动画与执行状态明确区分，不能制造正在工作的假象。任务结束后回到空闲画面。完成提示可短暂展示后收起，等待确认和失败状态的持续规则后续细化。

## 六个岗位的屏幕内容

| 岗位 | 画面构想 |
| --- | --- |
| 资料检索 | 翻动的文件卡片，当前文件名或搜索词 |
| 撰写修改 | 文字逐行出现、修改前后的小片段 |
| 联网调查 | 网页卡片与来源图标 |
| 会话记忆 | 便签、历史片段与关联线 |
| 命令执行 | 迷你终端，当前命令与完成状态 |
| 协作调度 | 任务看板，进行中和已完成数量 |

## 用户自定义

入口：点击电脑，在放大面板中选择“设置屏幕”。

- 上传本地图片作为壁纸，调整裁切位置。
- 六台电脑分别设置主题，也可一键统一。
- 开关时钟、岗位名称与任务状态。
- 调整屏幕亮度、动画速度，提供静态模式。
- 选择工作时是否自动切换到任务画面。
- 隐藏文件名、命令等具体内容，仅展示简短状态，便于截图和分享。

配置的保存范围、图片大小限制及导入导出方式，在实施时确定。

## 阅读与交互

正常俯视距离只显示图案、颜色和简短状态，避免堆积难以辨认的文字。点击电脑后打开清晰的大屏面板，显示完整内容及设置入口。

动画保持低干扰；支持减少动态效果。用户自定义壁纸与任务内容的切换应平滑，不能频繁闪烁。

## 实现要点

- 在现有显示器正面叠加独立屏幕面，无需重新生成整张桌子模型。
- 先检查真实 GLB，确定屏幕位置、角度、比例和边界，避免穿模或深度冲突。
- 动态屏幕由程序更新纹理；放大阅读和设置使用清晰的界面面板。
- 使用当前会话的真实任务事件驱动岗位状态，避免不同会话串屏。
- 控制纹理尺寸和刷新频率，隐藏或静态状态时减少更新；复用资源并正确释放。
- 用户上传图片作为内容处理，不作为可执行页面或脚本。

## 建议的首批范围

1. 六种岗位动态屏保。
2. 单台与统一设置的自定义壁纸。
3. 点击屏幕放大查看。
4. 真实工作事件切换、静态模式和敏感内容隐藏。

后续再扩展更多屏保、主题与个性化玩法。本文仅保存方向，不代表已经接入当前美术预览或正式插件。
