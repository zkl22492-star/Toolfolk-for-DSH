# 工作室角色美术 v1

生成方式：内置 image_gen，使用用户提供的蓝发鲸主题女仆角色参考图。原始输出保留在 Codex generated_images；本目录为项目实际使用的副本。

## 提示词与用途

- `window-day.png`：3:1 横向窗景，不含窗框。参考图左侧正常成人动漫比例角色，在花园中靠近窗户，微笑看向室内，抬手打招呼。保留蓝色长发、蓝眼、白色女仆头饰、藏蓝色裙装、白围裙、鳍形耳饰。柔和日光，无文字。
- `window-night.png`：以日间图为编辑目标，保持人物身份、姿势、位置、构图与花园；只改变为夜间，花园为低亮靛蓝色，来自室内的柔和暖光照亮面部和手掌，无窗框和文字。
- `chibi.png`：3:4 竖版平面海报，参考图右侧 Q 版角色，抱笔记本电脑并举拳加油，浅薄荷色纸张、手绘星星及文具图案，无文字、无墙面或相框。
- `motto.png`：3:4 励志海报，上半部大字“今日不努力”“明日少Token”，下半部同一 Q 版角色在电脑旁加油。米白纸张、芥末黄和珊瑚色点缀，深蓝手写粗体。

窗景由主题切换两张贴图；海报使用受室内灯光影响的材质。三张墙贴采用不同高度、尺寸和角度，挂在右墙内侧。客户端经宿主 Remote 通道加载，不依赖开发 HTTP 服务。

验证：`node scripts/check-client-mount.cjs` 检查实际客户端挂载、图片加载、明暗切换、拖动不误选、缩放旋转、窄屏及卸载。
