# 温暖微缩工作室 · 3D 资产 v1

这是一组按已确认概念图制作的可编辑、可导入 GLB 资产，采用程序化网格建模。当前为第一版造型与动作资产，尚未接入 DSH，也未完成正式产品性能验收。

## 文件

| 文件 | 内容 |
|---|---|
| `room.glb` | 开放式房间、浅木地板、窗户、装饰画 |
| `desk.glb` | 标准工位，含显示器、键盘、鼠标、杯子和小盆栽 |
| `chair.glb` | 鼠尾草绿办公椅 |
| `employee.glb` | 蓝色毛衣基础员工，含三个动作 |
| `plant.glb` | 独立盆栽 |
| `bookshelf.glb` | 模块化书架、书籍与收纳盒 |
| `console.glb` | 中央总控台及小型机器人 |
| `sofa.glb` | 双人沙发与抱枕 |
| `studio.glb` | 五工位组合场景，含研究、编程、设计和文档岗位造型 |
| `manifest.json` | 每个资产的包体积、三角面、网格数、包围盒、动画名与配色 |

## 坐标与组装

- 单位：米；Y 向上。
- 家具围绕局部 X/Z 中心放置；原点接近地面。房间地台向下延伸约 0.32 m。
- 基础员工为坐姿，局部面向 +Z；桌子的使用侧为 +Z。
- 组合时，员工在桌子 +Z 侧，绕 Y 轴旋转 π 面向桌面。
- 当前场景使用五个工位以保持留白，数量不是最终产品上限。
- 模型以 PBR 纯色材质着色，无外部贴图依赖。柔和灯光、接触阴影和背景由预览器提供，不烘焙在 GLB 中。
- 同一静态资产内按材质合并网格；员工保留可动画的部件层级。

## 动画

`employee.glb` 和 `studio.glb` 均提供 `Idle`、`Working`、`Error` 三个命名动作。场景动作同时驱动所有示例员工，仅用于展示。

动画为节点位移/旋转体系中的刚性部件旋转，没有蒙皮、标准人形骨骼、IK 或走路动画。最终需要更自然的职业动作时，应进一步精修和绑定。真实插件接入时，应对独立员工实例分别播放动作，而不是用整场演示动作代表所有调用。

## 本地预览和再生成

在项目根目录运行：

```powershell
npm ci --ignore-scripts --cache ./tmp/npm-cache
npm run assets:build -- --v1
npm run assets:verify -- --v1
npm run preview
```

打开 `http://127.0.0.1:4173/?version=v1`。支持旋转、缩放、平移、单资产查看、动作切换、暂停和 GLB 下载。该服务器只监听本机，不是 DSH 插件服务器。

建模源文件：`scripts/asset-kit.mjs`；导出脚本：`scripts/build-assets.mjs`。重新生成会更新本 v1 目录，后续新视觉版本应另建版本目录保留已确认资产。

预览器当前直接使用 Three.js，目的是检查资产本身；后续产品仍采用已确认的 React / React Three Fiber 技术路线。

## 当前验证与限制

- 所有 GLB 均经过重新加载、有效顶点、包围盒和动画绑定检查。
- 本地 Chromium 检查全部资产切换和三个动作，并保存真实渲染截图。
- 尚未在 DSH Web、官方桌面或外部建模软件中完成导入验收。
- 当前造型比视觉概念图简化；头发、服装、手部和职业动作仍有精修空间。
- 预览用屏幕文字为几何装饰线条；UI 明确标识为演示活动，无真实调用数据。
- 网格和材质由本项目代码生成；Three.js 的第三方许可保留在依赖中。
